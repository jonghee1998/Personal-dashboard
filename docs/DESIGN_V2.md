# 11단계 새 디자인(화이트·블루) 사양 대조표

11단계 마무리 Step 1 에서 [디자인 사양] (1)~(9) 를 6개 탭(홈·금융·뉴스·혜택·기록·구조) 실제 화면과 하나씩 대조한 결과다.
화면은 `npm run build` 후 `npm run screens` 가 합성 데이터(`scripts/screens/dashboard-fixture.mjs`)로 찍은 스크린샷(`.screens/`, 저장소에 넣지 않음)이고,
